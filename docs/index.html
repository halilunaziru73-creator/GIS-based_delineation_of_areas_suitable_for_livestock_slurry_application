GIS-MCDA Slurry Suitability

R² = 0.77 (best model: random-forest regression kriging)

ProblemFarmers spread livestock slurry as fertiliser, but standard maps only say 'yes' or 'no' to a zone, ignoring how risk actually varies across a field.
SolutionA continuous, regulator-compliant suitability surface built with regression kriging, tested head-to-head against deep learning.
ImpactR² = 0.77, beating both the old Boolean overlay and fancier deep-learning alternatives.
