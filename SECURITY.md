# Security Policy

This repository contains academic research code and data. It is not intended
to run as a production service and is not expected to handle sensitive user
data, so the typical security-vulnerability surface (authentication,
injection, data exposure) mostly does not apply.

## Reporting a concern

If you find something in this repository that could pose a security or data-
integrity risk — for example, a dependency with a known vulnerability, or a
script that could execute unsafe code on untrusted input — please open a
[GitHub Issue](../../issues) describing the concern. Response times are best
effort, as this is an independently maintained research repository.

## Supported versions

Only the latest tagged release is actively maintained. Older releases are
kept for citation and reproducibility purposes and are not patched.
